
# Masal Dünyası

## Proje Hakkında

Masal Dünyası, Türk masallarını dijital ortamda
bir araya getirmek amacıyla hazırlanmış
etkileşimli bir web sitesidir.

Bu proje, İstanbul Medipol Üniversitesi
Görsel İletişim Tasarımı Bölümü,
Programlamaya Giriş dersi kapsamında
hazırlanmıştır.

## Web Sitesinin Özellikleri

- 10 farklı masal
- Masal arama özelliği
- Masalları favorilere ekleme
- Favori masalları görüntüleme
- Masalları açıp okuma
- Bilgisayar ve telefon ekranlarına uyumlu tasarım

## Kullanılan Teknolojiler

- HTML
- CSS (HTML dosyasının içerisinde)
- JavaScript (HTML dosyasının içerisinde)

## Proje Nasıl Açılır?

1. Proje dosyalarını bilgisayarınıza indirin.
2. index.html dosyasını bir internet tarayıcısında açın.
3. Masalları inceleyin ve etkileşimli özellikleri kullanın.

Görsel dosyaları, HTML dosyasında belirtilen
konumlarda bulunmalıdır.
